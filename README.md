# Setup guide: animated GitHub profile for `thilak-codes`

This repo builds a terminal-style profile: a contribution heatmap, an ASCII portrait and a neofetch-style info card, all as animated SVGs. A GitHub Action refreshes the heatmap every day.

> Your GitHub username is `thilak-codes`, so the special repo is `thilak-codes/thilak-codes`.

## What you need
- A GitHub account
- Git: https://git-scm.com/downloads
- Python 3.10 or newer: https://www.python.org/downloads/ (tick "Add Python to PATH" on Windows)
- A clear, front-facing, well-lit photo of yourself (optional; a placeholder with your initials is used until you add one)

## Step 1: Create the special repository
1. Open https://github.com/new
2. Repository name: `thilak-codes` (exactly your username). GitHub shows a note saying it is a special repository.
3. Choose **Public**. Do **not** tick "Add a README" (you already have one in this folder).
4. Click **Create repository**.

## Step 2: Put these files in the repo
Unzip this folder, open a terminal inside it, then run:

```bash
git init -b main
git add .
git commit -m "Add animated profile README"
git remote add origin https://github.com/thilak-codes/thilak-codes.git
git push -u origin main
```
When asked to sign in, use your GitHub login (a browser window or a personal access token).

## Step 3: Allow the workflow to write to the repo
1. Repo > **Settings** > **Actions** > **General**
2. Scroll to **Workflow permissions**
3. Select **Read and write permissions** and click **Save**

## Step 4: Run the workflow once
1. Repo > **Actions** tab
2. If asked, click **I understand my workflows, go ahead and enable them**
3. Click **Update profile art** > **Run workflow** > **Run workflow**
4. Wait about 30 seconds until it shows a green tick. It commits a fresh `contrib-heatmap.svg`.

Now open https://github.com/thilak-codes. Your profile is live.

## Step 5 (optional): Use your own photo in the ASCII portrait
Do this on your own computer.

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r scripts/requirements.txt -r scripts/requirements-photo.txt
```

1. Save your photo as `source-photo.jpg` in the repo root.
2. Remove the background and boost contrast (the first run downloads a model, about 170 MB):
   ```bash
   python scripts/prep_photo.py source-photo.jpg
   ```
3. Convert to ASCII:
   ```bash
   python scripts/make_ascii_svg.py
   ```
4. Open `thilak-ascii.svg` in a browser to check it. Tips: face centered, bright even light, plain background.
5. Publish:
   ```bash
   git add thilak-ascii.svg
   git commit -m "Update ASCII portrait"
   git push
   ```

`source-photo.*` is in `.gitignore`, so your original photo is never uploaded.

## Step 6 (optional): Edit your info card
Open `scripts/make_info_card.py`, change the `LINES` list, then:
```bash
python scripts/make_info_card.py
git add info-card.svg && git commit -m "Update info card" && git push
```
Use `STATIC=1 python scripts/make_info_card.py` for a non-animated preview.

## Step 7 (optional): Test everything offline
```bash
pip install -r scripts/requirements.txt
python scripts/fetch_contributions.py --demo   # FAKE data, for testing only
python scripts/render_heatmap_svg.py
```
Do not commit the demo output; run the real fetch instead (`python scripts/fetch_contributions.py`).

## Make your heatmap look good
- Commit regularly. The heatmap shows real activity only.
- Push your Calculator and To-Do projects with a README in each, then pin them on your profile.
- Fix the typo "Adapatability" on your resume.

## Troubleshooting
| Problem | Fix |
|---|---|
| Profile README not showing | Repo must be Public, named exactly like your username, with `README.md` in the root |
| Broken image icons | Run the workflow once (Step 4); check the SVG file names match `README.md` |
| Action fails on "push" | Do Step 3 (read and write permissions) |
| Action says "No contribution cells found" | GitHub changed its HTML; open an issue or update `parse_calendar()` |
| Contributions missing | Commits count only if the email is linked to your account and they are on the default branch |
| `rembg` install fails | Skip it: the script still works without background removal (use a plain-background photo) |
| Animation not playing | It plays on page load and stops; refresh the profile page |
